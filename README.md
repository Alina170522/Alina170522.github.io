# Редизайн главной страницы УК «Левобережная»

Учебный проект: переработанная главная страница сайта управляющей компании. Макет сделан в Figma, затем сверстан на чистом HTML и CSS, без фреймворков и библиотек.

**Живая страница:** https://alina170522.github.io/

## Что изменено по сравнению с оригиналом
- Убраны пустые поля по краям, информация сгруппирована в блоки
- Строка поиска по сайту в правом верхнем углу (в оригинале поиск был внизу страницы)
- Быстрые сервисы (оплата ЖКУ, показания, история, заявки) вынесены на первый экран
- Добавлены блоки новостей, контактов и форма обратной связи

## Что реализовано в вёрстке
- Адаптив от 360 px до десктопа (проверено на 390, 768, 1024 и 1440 px), без горизонтальной прокрутки
- Семантическая разметка: `header`, `nav`, `main`, `section`, `footer`, подписи `aria-label`
- Видимые состояния фокуса (`:focus-visible`) и учёт `prefers-reduced-motion`
- CSS-переменные для цветов, `clamp()` для адаптивной типографики, CSS Grid и Flex
- SVG-иконки через `<symbol>` и `<use>`
- Файл `index.html` и папка `assets/`, без сборки и библиотек
- Для скорости: preload фоновой картинки, размеры у изображений (нет сдвига макета), WebP

## Как сделана вёрстка по макету
Размеры, цвета, шрифты и отступы взяты из кадра «После редизайна» в Figma: зелёный `#00a00b`, текст `#444`, фон секций `#f6f7f6`, карточки сервисов 330×150 с разделителями, шапка и меню по сетке макета. Цвета вынесены в CSS-переменные. Иллюстрация, логотип и иконки выгружены из Figma; фон сжат до WebP (145 КБ вместо 2,2 МБ).

В макете нет поиска, поэтому строку поиска я добавила сама в правый верхний углу, в стиле остальных полей.
