# Редизайн главной страницы УК «Левобережная»

Учебный проект: переработанная главная страница сайта управляющей компании. Макет сделан в Figma, затем сверстан на чистом HTML и CSS, без фреймворков и библиотек.

**Живая страница:** https://alina170522.github.io/

## Что изменено по сравнению с оригиналом
- Убраны пустые поля по краям, информация сгруппирована в блоки
- Поиск по сайту перенесён в правый верхний угол
- Быстрые сервисы (оплата ЖКУ, показания, история, заявки) вынесены на первый экран
- Добавлены блоки новостей, контактов и форма обратной связи

## Что реализовано в вёрстке
- Адаптив для ширин от 360 px до десктопа (проверено на 390, 768, 1440 px)
- Семантическая разметка: `header`, `nav`, `main`, `section`, `footer`, подписи `aria-label`
- Видимые состояния фокуса (`:focus-visible`) и учёт `prefers-reduced-motion`
- CSS-переменные для цветов, `clamp()` для адаптивной типографики, CSS Grid и Flex
- SVG-иконки через `<symbol>` и `<use>`
- Один файл `index.html`, без сборки

## Шрифты
Onest и Playfair Display (Google Fonts).
